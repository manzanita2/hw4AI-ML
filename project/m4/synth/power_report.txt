Dominant contributor
---------------------------------------------------------------------
  Sequential cells dominate at 0.407 W (48.8 %), driven almost
  entirely by internal/clock power of the ~96.6k async-reset flops
  (PE pipeline chains, weight_store, the two 257-bit AXIS FIFOs).
  The clock network is the second contributor at 0.305 W (36.6 %) --
  expected for a flop-heavy systolic array. Combinational switching
  (the bf16 mul / fp32 add datapaths) is only 0.122 W (14.6 %).

IMPORTANT -- estimate basis
---------------------------------------------------------------------
  This is OpenROAD's STATIC activity estimate (default internal
  switching-activity propagation), NOT a back-annotated VCD power
  run. No SAIF/VCD from the cocotb co-sim was annotated onto the
  netlist. The absolute watts should be read as an order-of-magnitude
  signoff estimate; the relative split (sequential >> clock >>
  combinational) is the trustworthy takeaway. A VCD-back-annotated
  run (feeding tb_top's gemm-tile activity into report_power) is the
  natural M4 follow-up for a sharper number, and the conv tile's real
  duty cycle (LOAD state toggles the weight mux only once per tile)
  would lower the combinational/clock figures.
